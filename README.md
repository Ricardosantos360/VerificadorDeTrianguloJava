
# 🔺 Verificador de Triângulos em Java

Um mini projeto desenvolvido em **Java** que permite verificar se três segmentos formam um triângulo e identificar sua classificação e se é possível formar de maneira simples e interativa.

## 💻 Funcionalidades

- Ajuste dos três segmentos utilizando sliders.
- Verificação automática da condição de existência de um triângulo.
- Identificação dos tipos:
  - Equilátero
  - Isósceles
  - Escaleno
- Interface gráfica intuitiva utilizando Java Swing.

## 🛠️ Tecnologias utilizadas

- Java
- Java Swing
- NetBeans IDE

## 🎯 Objetivo

Projeto desenvolvido com o objetivo de praticar conceitos fundamentais de programação em Java, como variáveis, estruturas condicionais, operadores lógicos e manipulação de componentes gráficos.
